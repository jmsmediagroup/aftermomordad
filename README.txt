AFTERMOMORDAD.COM: THE SITE
A plain static site. No database, no server code except the one sign-up
function. Netlify serves this folder as it is.

HOW IT IS MADE
  Every page is generated by one script, run from the project folder
  (02_After Mom or Dad):
      python3 09_site/build_site.py
  Edit the script, not the HTML. The one file edited by hand is
  assets/books.js: paste a book's Amazon links there when it is published,
  then run the script again so "In preparation" changes to "Out now".

  The design, the sign-up function and the browser script came from
  widowsguide.org's generator, with this series' name, colors and pages.

PAGES (pre-launch)
  /                  what the series is, "How long has it been?", the six books
  /books/            the seven books, with the same picker
  /books/<title>/    one page per book: in preparation, sign-up, the books
                     before and after it
  /start/            the free checklist (PDF in assets/, from 00_templates/04_lead-magnet)
  /questions/        every chapter question; one page per chapter under /books/<book>/
  /about/ /help-tonight/ /contact/ /privacy/ /terms/
  /thanks/           shown after a sign-up (noindex)
  /1/ ... /6/        short links to be printed (with QR codes) in the books.
                     Each goes to the book's page here until its Amazon link
                     is in assets/books.js, then to Amazon.

ONE-TIME SETUP, IN THIS ORDER
  1. Netlify: Add new site > Import from GitHub > jmsmediagroup/aftermomordad.
     No build command; publish directory "." (netlify.toml already says so).
  2. Netlify > Domain management: add aftermomordad.com, and follow Netlify's
     DNS instructions at the registrar. Netlify issues the certificate itself.
  3. MailerLite > Subscribers > Groups: create a group, e.g. "Aftermomordad.com",
     and copy its ID from the address bar. The "interest" field already exists
     in the account (it was made for widowsguide.org), so nothing to add there.
  4. Netlify > Site configuration > Environment variables, for THIS site:
         MAILERLITE_API_KEY    the same account's API token
         MAILERLITE_GROUP_ID   the new group's ID
     Then redeploy, so the sign-up function picks them up.
  5. Email: set up forwarding for hello@aftermomordad.com at the registrar.
     The site prints that address on every page.
  6. Test: sign up with your own address on the live site. If it fails, the
     reader lands on /thanks/?ok=0, which tells them to email instead, and the
     reason is in Netlify > Logs > Functions.

AFTER IT IS LIVE
  - Google Search Console and Bing Webmaster Tools: verify the domain, then
    submit /sitemap.xml. For Bing's file method, put its code in BING_VERIFY
    at the top of build_site.py and rebuild.
  - IndexNow: after each deploy, run   python3 09_site/indexnow.py
    The key is at the top of build_site.py and published at /<key>.txt.
  - Google Analytics: create a property (or a second data stream in the
    existing one), put its ID in GA4_ID, rebuild. The privacy page follows.

THE CRISIS LINES
